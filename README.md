# Modern Homes Website

A responsive business website for Modern Homes, a Chennai-based construction company established in 2001.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript

## Current features
- Responsive navigation
- Mobile menu
- Project showcase
- Services section
- WhatsApp and phone CTAs
- Email contact
- Basic SEO metadata
- Modern editorial/architectural visual style

## Before deployment
1. Replace the project placeholders with real project photographs.
2. Add the office address if you want it displayed.
3. Add genuine testimonials when available.
4. Update project names/locations.
5. Replace the temporary logo crop if a higher-resolution logo is available.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy
Push the folder to GitHub and import the repository into Vercel.

### Project images
Five supplied Modern Homes project/design visuals are stored in `images/projects/` and used across the homepage.
